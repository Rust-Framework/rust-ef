## Current State Analysis

### M1.3 BoolExpr::raw 收窄 — 未开始

当前 `BoolExpr::Raw(String)` 是公开变体，任何外部代码可通过 `BoolExpr::Raw("...".to_string())` 直接构造，`BoolExpr::raw()` 也是 pub 方法。security.md:40 声称"用户 API 不暴露 Raw 构造入口"是虚假声明。

仅将 `raw()` 改 `pub(crate)` 是补丁式修改——变体仍可外部构造。**根因修复**：引入 `pub(crate) struct RawSql(pub(crate) String)` 包装，使外部代码无法命名该类型，从而无法构造 `Raw` 变体。

**编辑 5 — [postgres/provider.rs](file:///d:/GitCode/RF/rust-ef/crates/postgres/src/provider.rs)**

`new()` 改默认 Require（line 18-24）：
```rust
/// Creates a provider with TLS required (secure-by-default, v1.6+).
///
/// Uses a `native_tls::TlsConnector` built from the platform's default
/// root certificate store. For plaintext connections (local dev only),
/// use [`PostgresProvider::new_insecure`].
pub fn new(connection_string: &str, pool_size: usize) -> EFResult<Self> {
    let connector = native_tls::TlsConnector::builder()
        .build()
        .map_err(|e| EFError::Connection(format!("TLS connector init failed: {}", e)))?;
    Self::new_with_tls(connection_string, pool_size, PgTlsMode::Require(connector))
}

/// Creates a provider with TLS disabled (plaintext, local dev only).
pub fn new_insecure(connection_string: &str, pool_size: usize) -> EFResult<Self> {
    Self::new_with_tls(connection_string, pool_size, PgTlsMode::Disable)
}
```

## Assumptions & Decisions

1. **RawSql 包装优于仅 pub(crate) raw()**：仅改 `raw()` 可见性是补丁——`Raw` 变体仍可外部构造。RawSql `pub(crate)` 从类型层面关闭构造入口，是根因修复。
2. **bool_expr_tests.rs 的 raw 测试移入 compile.rs 单元测试**：集成测试无法访问 `pub(crate)`，且 raw SQL 编译是内部行为。单元测试覆盖更准确。
3. **PG new() 默认 Require 使用系统默认 TlsConnector**：`native_tls::TlsConnector::builder().build()` 使用平台根证书库。本地开发服务器无有效证书时 `new()` 会失败——这是 secure-by-default 的正确行为，用 `new_insecure()` 逃生。
4. **MySQL new()/new_lazy() 强制 Required 覆盖连接串 ssl-mode**：convenience 构造器强制安全；需连接串控制时用 `new_with_tls`/`new_lazy_with_tls`。
5. **DI 扩展 use_postgres/use_mysql 自动变安全**：委托给 `new()`/`new_lazy()`，无需新增 `use_*_insecure`——`use_*_with_tls` 已是逃生舱。
6. **CLI 用 new_insecure**：scaffold 是开发工具连本地库，TLS 逃生舱合理。
7. **M2-M6 按已批准计划执行**：本计划不重复细节，仅记录执行顺序与验证门。
