# rust-ef v1.5 实现计划 — tracing 集成 + SemVer 严格化 + MySQL TLS

## Context

v1.4.1 完成了生产硬化（6 个警告修复 + 8 维度评估），其中 2 个维度标记为部分就绪：
- **可观测性 ⚠️**：无 tracing/log 集成，无法监控慢查询和连接池
- **SemVer ⚠️**：minor 版本含 breaking change，无 deprecation 期

v1.5 目标：清除这两个 ⚠️，同时补齐 MySQL TLS 显式 API（对齐 PgTlsMode 模式）。用户要求规划 + 全部实现。

## 实现顺序

```
Phase 1: MySQL TLS（功能 3）→ 独立，参照 PgTlsMode 现成模式
Phase 2: tracing 集成（功能 1）→ 跨 4 个 crate，核心是 observability.rs
Phase 3: SemVer 严格化（功能 2）→ 文档 + 版本号，依赖前两个功能的最终 API
```

```rust
/// TLS mode for MySQL connections.
///
/// Unlike `PgTlsMode`, this enum does not carry a `TlsConnector` — sqlx
/// manages TLS internally via its `tls-native-tls` feature. CA certificates
/// are configured via the connection string's `ssl-ca` parameter.
#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum MySqlTlsMode {
    /// Disable TLS — plaintext connections only.
    Disabled,
    /// Require TLS — connection fails if server doesn't support TLS.
    Required,
    /// Require TLS with CA certificate verification.
    VerifyCa,
    /// Require TLS with CA certificate and hostname verification.
    VerifyIdentity,
}

impl From<MySqlTlsMode> for sqlx::mysql::MySqlSslMode {
    fn from(mode: MySqlTlsMode) -> Self {
        match mode {
            MySqlTlsMode::Disabled => Self::Disabled,
            MySqlTlsMode::Required => Self::Required,
            MySqlTlsMode::VerifyCa => Self::VerifyCa,
            MySqlTlsMode::VerifyIdentity => Self::VerifyIdentity,
        }
    }
}
```

### 步骤 1.3：mysql/src/provider.rs — 添加 new_with_tls / new_lazy_with_tls 方法

在 `MySqlProvider` impl 块中（`new_lazy` 之后）添加：

```rust
/// Creates a provider with explicit TLS configuration.
///
/// The TLS mode overrides any `ssl-mode` in the connection string.
/// For CA certificate verification, provide the CA via the connection
/// string's `ssl-ca` parameter.
pub async fn new_with_tls(connection_string: &str, tls: MySqlTlsMode) -> EFResult<Self> {
    let mut options: sqlx::mysql::MySqlConnectOptions = connection_string
        .parse()
        .map_err(|e| EFError::Connection(format!("MySQL URL parse: {}", e)))?;
    options = options.ssl_mode(tls.into());
    let pool = sqlx::MySqlPool::connect_with(options)
        .await
        .map_err(|e| EFError::Connection(format!("MySQL connection failed: {}", e)))?;
    Ok(Self { pool })
}

/// Creates a lazy provider (no immediate connection) with explicit TLS.
pub fn new_lazy_with_tls(connection_string: &str, tls: MySqlTlsMode) -> EFResult<Self> {
    let mut options: sqlx::mysql::MySqlConnectOptions = connection_string
        .parse()
        .map_err(|e| EFError::Connection(format!("MySQL URL parse: {}", e)))?;
    options = options.ssl_mode(tls.into());
    let pool = sqlx::MySqlPool::connect_lazy_with(options);
    Ok(Self { pool })
}
```

### 步骤 1.4：mysql/src/di_extension.rs — 添加 use_mysql_with_tls 扩展方法

```rust
}
```

## 功能 2：tracing 集成（慢查询 + 连接池指标）

### 设计决策

- **tracing 作为可选 feature**：符合现有 chrono/uuid/decimal 模式
- **guard 模式封装**：`QueryGuard`、`PoolAcquireGuard`、`SaveChangesGuard`，feature 关闭时为 ZST no-op
- **慢查询阈值可配置**：`DbContextOptionsBuilder::slow_query_threshold()`
- **trait 默认方法注入**：`IDatabaseProvider` 和 `IAsyncConnection` 添加 cfg-gated `set_slow_query_threshold()` 默认方法（非 breaking change）

### 步骤 2.2：创建 core/src/observability.rs — 可观测性 guard 模块

新文件：`crates/core/src/observability.rs`

三个 guard 类型，每个都有 feature 开启/关闭两个版本：

```rust
//! Tracing/observability instrumentation guards.
//!
//! When `tracing` feature is disabled, all guards are zero-sized types
//! with no-op constructors — eliminated entirely by the compiler.

use std::time::{Duration, Instant};

// ==================== QueryGuard ====================

#[cfg(feature = "tracing")]
pub struct QueryGuard { sql: String, start: Instant, threshold: Option<Duration> }

#[cfg(feature = "tracing")]
impl QueryGuard {
    pub fn new(sql: &str, threshold: Option<Duration>) -> Self {
        tracing::debug!(target: "rust_ef::query", sql = %sql, "query started");
        Self { sql: sql.to_string(), start: Instant::now(), threshold }
    }
}

#[cfg(feature = "tracing")]
impl Drop for QueryGuard {
    fn drop(&mut self) {
        let elapsed = self.start.elapsed();
        let elapsed_ms = elapsed.as_millis() as u64;
        if let Some(threshold) = self.threshold {
            if elapsed >= threshold {
                tracing::warn!(
                    target: "rust_ef::query", sql = %self.sql,
                    elapsed_ms, threshold_ms = threshold.as_millis() as u64,
                    "slow query detected"
                );
                return;
            }
        }
        tracing::debug!(target: "rust_ef::query", sql = %self.sql, elapsed_ms, "query completed");
    }
}

#[cfg(not(feature = "tracing"))]
pub struct QueryGuard;

#[cfg(not(feature = "tracing"))]
impl QueryGuard {
    pub fn new(_sql: &str, _threshold: Option<Duration>) -> Self { Self }
}

// ==================== PoolAcquireGuard ====================

#[cfg(feature = "tracing")]
pub struct PoolAcquireGuard { provider: &'static str, start: Instant }

#[cfg(feature = "tracing")]
impl PoolAcquireGuard {
    pub fn new(provider: &'static str) -> Self {
        Self { provider, start: Instant::now() }
    }
}

#[cfg(feature = "tracing")]
impl Drop for PoolAcquireGuard {
    fn drop(&mut self) {
        tracing::info!(
            target: "rust_ef::pool", provider = self.provider,
            acquire_ms = self.start.elapsed().as_millis() as u64,
            "connection acquired"
        );
    }
}

#[cfg(not(feature = "tracing"))]
pub struct PoolAcquireGuard;

#[cfg(not(feature = "tracing"))]
impl PoolAcquireGuard {
    pub fn new(_provider: &'static str) -> Self { Self }
}

// ==================== SaveChangesGuard ====================

#[cfg(feature = "tracing")]
pub struct SaveChangesGuard { start: Instant }

#[cfg(feature = "tracing")]
impl SaveChangesGuard {
    pub fn new() -> Self { Self { start: Instant::now() } }
}

#[cfg(feature = "tracing")]
impl Drop for SaveChangesGuard {
    fn drop(&mut self) {
        tracing::info!(
            target: "rust_ef::save_changes",
            elapsed_ms = self.start.elapsed().as_millis() as u64,
            "save_changes completed"
        );
    }
}

#[cfg(not(feature = "tracing"))]
pub struct SaveChangesGuard;

#[cfg(not(feature = "tracing"))]
impl SaveChangesGuard {
    pub fn new() -> Self { Self }
}
```

### 步骤 2.8：三个 provider 的 provider.rs — get_connection 插桩 + set_slow_query_threshold

每个 provider 结构体添加 cfg-gated 字段：
```rust

```


IDatabaseProvider impl 添加：
```rust
#[cfg(feature = "tracing")]
fn set_slow_query_threshold(&self, threshold: std::time::Duration) {
    self.slow_query_threshold_ms
        .store(threshold.as_millis() as u64, std::sync::atomic::Ordering::Relaxed);
}
```

get_connection 方法添加 guard + 阈值传递：
```rust
async fn get_connection(&self) -> EFResult<Box<dyn IAsyncConnection>> {
    let _guard = rust_ef::observability::PoolAcquireGuard::new("ProviderName");
    let conn = self.inner.get_connection().await?;  // 或现有获取逻辑
    #[cfg(feature = "tracing")]
    {
        let ms = self.slow_query_threshold_ms.load(std::sync::atomic::Ordering::Relaxed);
        if ms > 0 {
            conn.set_slow_query_threshold(std::time::Duration::from_millis(ms));
        }
    }
    Ok(conn)
}
```

## 假设与决策

1. **tracing 作为可选 feature**：符合现有 chrono/uuid/decimal 模式，feature 关闭时零开销
2. **MySqlTlsMode 不携带 TlsConnector**：sqlx 内部管理 TLS，与 PgTlsMode 设计不同但合理
3. **v1.5 无 breaking change**：tracing 和 MySQL TLS 均为纯新增，trait 默认方法非 breaking
4. **deprecation 期 1 个 minor 版本**：vN.x 标记 deprecated → vN.(x+1) 移除
5. **不修改 interceptor.rs 编码损坏**：pre-existing 问题，非本次范围
